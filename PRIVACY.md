# Privacy policy

Five is a local-first Chrome and Brave extension. It does not collect, sell, transmit, or analyze personal data.

## Data stored locally

Five stores tasks, ideas, routines, categories, Daybook history, timer settings, presentation preferences, and the user-configured blocklist in `chrome.storage.local`. This data remains in the browser profile unless the user removes it or uninstalls the extension.

Five does not require an account and does not include analytics, telemetry, advertising, or remote application services.

## Browser permissions

- `storage` persists the local application state.
- `alarms` keeps recurring tasks, focus timers, and temporary blocklist pauses working when the new-tab page is closed.
- `declarativeNetRequestWithHostAccess` and host access let Chrome enforce rules for domains the user explicitly adds to the blocklist. Five does not read page contents or browsing history.

The bundled presentation wallpapers and fonts are served from the extension package. Photographer-credit links open the corresponding Unsplash pages only when the user chooses to follow them.

## Data sharing

Five does not share data with its developer or third parties. There is no backend service to receive it.

## Changes

Material changes to this policy will be documented in the repository and reflected in a new extension release.
