# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

## Product decisions

- This is a Chrome Manifest V3 new-tab extension, not a static web mock.
- Package releases as a versioned Chrome Web Store ZIP under `release` while retaining `dist` as the load-unpacked build. Keep the package and manifest versions aligned and include branded 16, 32, 48, and 128px raster icons. The icon is an ink rounded square with a Commit Mono `5` and an orange accent dot as its period (`assets/five-icon.svg`); the 16/32px rasters use a tighter crop so the glyph stays legible.
- The October 2026 redesign handoff defines the current visual system: a neutral `#F5F5F2` ground, white surfaces, ink text, and one orange accent (`#C2410C` light / `#F97316` dark). Keep the tokens in `src/styles.css` as the source of truth.
- Use the accent only for the Now state, the Start button, and focus progress. Everything else stays neutral.
- Do not use letterspaced all-caps labels anywhere.
- Type: bundled Schibsted Grotesk (OFL, variable) for titles, headings, and body text; bundled Commit Mono (OFL, 400/500/600) only for small meta — dates, counts, slot numbers, timers, keyboard hints — and the `five` wordmark, which matches the icon's mono 5. The user tried Commit Mono everywhere and rejected it; never use Geist, Inter, or other Vercel fonts. Body 15px; scale: h1 34/600/-0.03em, Now task 23/500/-0.02em, tasks 16–17/400, meta 12.5–13.
- Radii are 14–16px for rows and cards and 999px for pills. Touch targets are at least 44px. The container is 1180px wide with 36px/48px padding.
- System theme is the default. Settings offers a swatch picker (each tile previews the theme with its own tokens) with nine persisted themes: System, Light, Dark; atmospheric backgrounds Paper (warm grain), Dot grid (notebook dots), Blueprint (navy drafting grid), Dusk (ember glow under frosted glass); and two brutalist themes, Brutal (concrete ground, white slabs, black 2px rules, hard offset shadows, square corners, `#FF4F00`) and Acid (black, white rules, `#D4FF00`). Themes are token sets on `[data-theme]` (plus `--bg-image`/`--bg-size`/`--surface-filter`); each keeps a single accent with the same accent rules. Brutalist structure overrides never apply to Presentation mode. The theme is mirrored to `localStorage` so new tabs paint in the right theme before `chrome.storage` resolves.
- The header is the lowercase `five` wordmark plus a mono date, a segmented Today `N/5` · Later · Ideas nav (active item is a raised pill, nav uses `aria-current`), and icon buttons for Hide list and Settings. Do not show per-page subtitles, taglines, or a logo box.
- Today holds at most five slots. Done tasks keep their slot (filled check, struck text) until the user clears them or the day ends, and completion records stay in the Daybook either way.
- Exactly one open Today task is Now. It defaults to the first open task and can be changed by clicking a row title, the row's Focus button, ↑/↓ or J/K, or keys 1–5. Enter starts focus on Now. The list is never fixed: rows in Today (including done-in-slot rows) and Later reorder by dragging the handle (Today's slot number turns into a grip on hover), by ↑/↓ while the handle has focus, or with Shift+↑/↓ (Shift+J/K) to move the Now task. Reordering persists the explicit `order` field; Later reorders keep rows hidden behind Show more in place. The Now row is a raised card with an accent `Now · {category}` line and the `Start {mm:ss}` pill.
- The focus timer starts from the Now row and opens a dark full-screen Focus mode (task title, large mono timer, accent progress bar, Pause · Done · Switch task, next-up and blocked-site footer, Esc to exit). There is no floating timer. Focus blocks are 25/50 minutes, rests 10/20 minutes, and every completed 25 focus minutes counts as one session.
- Open Today tasks can be sent to Later or back to Ideas for re-triage, via hover-revealed row buttons (↓ and lightbulb) or L / I for the Now task. A task sent back lands at the top of Ideas, so it is the next one the Triage card shows.
- Open tasks are editable in place in Today, Later, and the Ideas Triage card: one inline editor holds the title (an auto-growing field sized like the title it replaces) and the hint. Open it with the hover pencil button, double-clicking a title (single-clicking the Triage title), E for the title or H for the hint (Now task on Today, current idea in Triage), or clicking the hint. Enter or clicking away saves, Esc cancels, Tab moves between fields. The title field accepts composer syntax: `#tag` recategorizes and `// hint` replaces the hint; an empty title keeps the old one. Done tasks are not editable.
- Any task can carry an optional one-line hint (max 140 chars) that decodes a compressed title. Set it with `title // hint` in any composer (`//` must follow whitespace so URLs are untouched; a `#tag` works on either side) or the inline editor. An empty hint clears it. Hints render as a small muted sans line under the title in Today, Later, Ideas (list and Triage card), and Focus mode, and travel with the task between lists.
- Hide the Today composer when all five slots are taken. When Today is full, moving a task up from Later or Ideas (or pressing N on Today) opens a "swap with which?" picker: an open slot goes to Later, a done slot is cleared, and the incoming task takes that slot's position.
- The Today sidebar holds the Daybook card (a mono `N done` count; an 08–20 day strip with a tick per completion, the elapsed span shaded, and a now marker; a newest-first crossed-off list keyed by mono completion time with faint strikethrough, collapsed after five behind "N earlier"; and a compact inset date-keyed daily note that resets each day — no slot numbers or `--` placeholders) and a hairline status list: Routines (with due routines checkable inline) · Blocked during focus · Focus today.
- Recurring definitions are capped at five and managed on the Routines sub-page (segmented Daily · Weekdays · Weekly, with a day picker for Weekly). Due routines never take a Today priority slot.
- Categories are capped at five. Typing `#tag` in any composer assigns or creates the category. There are no category dropdowns, and chips are neutral outlined pills.
- Later is a single 760px column with hairline rows, a ↑ Today button, and "Show N more" after eight rows.
- Ideas is an unlimited pre-triage inbox and a first-class tab. An inverted Triage card resolves one idea at a time (Today · Later · Drop · Skip; keys T/L/X/S). The list below has no per-row actions; selecting a row loads that idea into the card.
- Discarding an Idea permanently removes it; do not route discarded Ideas into the completed-task archive where they become invisible.
- Paused recurring definitions must not surface due instances or keep distraction blocking active. Generated recurring-instance history is retained for 31 days to bound local storage growth.
- Global keys: N new, ↑/↓ or J/K pick Now, Shift+↑/↓ move Now, Enter start focus, 1–5 set Now, L send Now to Later, I send Now back to Ideas, E edit the Now task, H edit the Now hint, Space start/pause timer, Esc exit focus, G T / G L / G I switch lists. Never fire shortcuts while typing.
- Settings is a sub-page holding theme, timer lengths, categories, and the blocklist.
- Keep implementation modular: typed domain models, a storage repository with versioned migrations, pure domain helpers, React components, and an event-driven service worker.
- Use Chrome storage.local for task data and dynamic declarativeNetRequest rules for site blocking.
- Never request all-sites host access at install. Blocking uses `declarativeNetRequestWithHostAccess` plus `optional_host_permissions`; adding a site requests `*://*.domain/*` from the submit gesture (the site is only added if granted), removing it releases the origin, and sites without access show an Allow button (Allow all for several) and a "needs your OK" sidebar status. `index.html` is a dynamic-URL web-accessible resource so link-click navigations can be redirected to it.
- Settings has a Backup section: Export downloads the full state as `focus-five-backup-YYYY-MM-DD.json`; Restore accepts that file or a raw `fiveState` object, refuses invalid JSON, newer schemas, and damaged tasks, shows a Backup vs Now count comparison, and downloads a safety copy of current data before replacing it.
- The store name is `Focus Five: New Tab To-Do List` and the promo tagline is "Today's five tasks, on every new tab." Store copy is plainspoken and says it's a new tab; avoid preachy or smug lines ("what matters", "get to work") and the old "stops at five".
- Chrome Web Store materials (listing copy, privacy answers, permission justifications, 1280×800 screenshots, promo tiles) live in `store/`. Regenerate screenshots from seeded demo data, never the user's real tasks.
- Blocklist suspension is one standard 30-minute action, limited to three uses per local calendar day. Show the remaining daily allowance as a compact counter and do not consume another use while a pause is already active. Let users resume blocking early; treat cancellation within the first five minutes as an undo that restores the allowance, while later cancellation still counts as a used pause.
- Presentation mode (the Hide list button) is a persisted one-click privacy state. While active, do not render task content, counts, navigation, or settings; show the selected bundled Unsplash wallpaper with only discreet reveal/wallpaper controls, photo credit, and a small timer readout when a session is in progress. Offer six persisted choices: Misty lake, Lonely road (default), Wanderlust, Forest bend, Sunset road, and Open country.
- Give Presentation mode a restrained, non-private visual anchor in the center: a clock, date, and the small `five` wordmark. Do not reintroduce motivational copy or task-like content over the wallpaper.
